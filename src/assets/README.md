Static assets imported by the React app.

Use this folder when an image should be bundled by Vite and referenced from code with an import.

- `covers/`: existing resource cover placeholders.
- `design/`: UI reference or layout images used by the prototype code.
- `mock/students/`: mock student avatar images.
- `mock/classes/`: mock class-related images.
- `mock/resources/`: mock resource images used by data records.
